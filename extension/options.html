Connect the extension to your Google Sheet.

Quick setup

  1. Open your Google Sheet → Extensions → Apps Script.
  2. Paste in Code.gs from this project and set your own SECRET.
  3. Run setup once, then Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  4. Paste the web app URL and your secret below.
